AI Object Detection

Deep-learning object detection for detecting humans and wildlife from aerial thermal imagery using YOLO models, deployed through a web interface.

Computer VisionYOLOv11FastAPIReact

Problem

Monitoring wildlife in large conservation areas is challenging due to limited visibility and wide geographic coverage. Manual observation often fails to detect animals or humans in nighttime conditions or dense environments.

Solution

Developed an AI-powered object-detection system using YOLO models trained on UAV thermal imagery. The system integrates a FastAPI backend and a web interface that lets users upload images and automatically detect objects with bounding-box visualization.
